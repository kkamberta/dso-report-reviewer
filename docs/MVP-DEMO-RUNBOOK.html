DSO Report Reviewer MVP Demo Runbook

Run a controlled customer-facing demo showing how a scan artifact becomes an annotated XLSX, executive markdown summary, and human review queue.

Open Customer Pitch Open Operator UI Health Check

Purpose

Current MVPLocal demo agent, deterministic findings, and human approval gate.
Not ProductionNo live scanner integration, no Jira/ServiceNow, and no automatic risk acceptance.
Downloaded XLSX/markdown must reflect reviewer approval decisions. UI-only status changes are not acceptable for this demo.

Start Demo Agent

./scripts/start-demo.sh

Keep this process running during the demo. It prints the customer pitch, operator UI, and runbook URLs after the health check passes. The script uses a repo-local .uv-cache/ by default so it can run in restricted environments.

Manual Start Fallback

uv run --with openpyxl python demo_agent.py --host 127.0.0.1 --port 8088

Health Check

curl -s http://127.0.0.1:8088/healthz

Expected response: {"status":"ok"}

Room Demo Flow

1Open pitchUse /customer-pitch.html. Explain this is not another scanner; it reviews scanner output.
2Open UIUse /ui/index.html. Confirm demo agent online status.
3Reset demoClick Reset demo. This restores build-92619 to the clean pre-approval state.
4Run demo jobClick Run demo job. Confirm build-92619 completes with 4 findings and row 42 has technical command boxes.
5Before approvalOpen /outputs/summary.md. Rows 18 and 33 should be in Human Review Queue.
6Approve row 18Approve Production secret in application-prod.yml. UI reloads from demo agent.
7After approvalSummary shows row 18 under Approved Review Decisions and row 33 still pending.

Reset Demo By API

curl -s -X POST http://127.0.0.1:8088/demo/reset

Create Demo Job By API

curl -s -X POST http://127.0.0.1:8088/webhooks/scan-finished \
  -H 'Content-Type: application/json' \
  -d '{"job_id":"build-92619","project":"ap2065","priority":"high","scanner":"mixed","artifact_url":"https://ci.example/artifacts/report.xlsx"}'

Approve Row 18 By API

curl -s -X POST http://127.0.0.1:8088/jobs/build-92619/reviews \
  -H 'Content-Type: application/json' \
  -d '{"row_id":18,"review_status":"approved","reviewer_note":"Approved after confirming credential rotation plan."}'
